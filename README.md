The bounty wanted one line of an out-of-office reply, the funniest one I could manage in 140 characters. Mine is from somebody who has gone to the lake till Monday and roped the local fish into a confidentiality agreement about the state of their inbox, which felt about right for a person who checks email on holiday and is not proud of it.

`main.ts` writes that single line to `/output/entry.txt`, checks it fits the rules first (one sentence, 140 characters at most, no line breaks), and reads the file back to make sure what landed on disk is the line it meant to write. Fixed string, no network, no clock, same output every run.

## Run it

```sh
node main.ts
```
